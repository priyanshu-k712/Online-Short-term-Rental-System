# Online Short Term Rental System

A small teaching project inspired by Airbnb. The implementation uses React, FastAPI, and MongoDB and covers four core modules:

1. User registration and login with guest/host roles.
2. Host property management (create, view, edit, delete).
3. Public property listing and basic location/price search.
4. Guest booking, booking history, and cancellation.

Payment gateway integration, maps, chat, email verification, and full administration are intentionally excluded from this student release.

## Quick start

See `docs/IMPLEMENTATION_GUIDE.md` for detailed setup instructions, environment configuration, MongoDB setup, GitHub branching, testing, troubleshooting, and demonstration preparation.

- Backend directory: `backend/`
- Frontend directory: `frontend/`
- API docs after the backend starts: <http://127.0.0.1:8000/docs>
- Frontend after Vite starts: <http://localhost:5173>

Do not commit `.env` files or database passwords to GitHub.
